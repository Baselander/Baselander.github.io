Capabilities

不是聊天框，是坐在你旁边的那个

聊天谁都会。她记得你的课表、你的收件箱、你的错题本；她知道今天几号、下一节课在哪、哪个作业明天要交。 她要动手的时候会先问一句，你点头她才做。

◔

听懂你的作业

你把钉钉/群里的消息丢给她，她拆成一条条待办：科目、截止时间、要不要交。拿不准的会回来问你，不瞎建。

收件箱钉钉原文自动去重

盯住每个 DDL

按你的课表推截止时间，提前一小时提醒，到点再提醒一次。上课和安静时段一律不打扰你。

课表推断提前提醒上课静音

陪你专注

番茄钟一开，她闭嘴、只演工作；连续专注 50 分钟提醒你喝水，切去娱乐窗口会轻轻念你一句。

专注模式喝水提醒不打扰

陪你把题啃透

讲概念、换更简单的说法、往深里讲、出同类型新题、照错题出相似题。看不到的题她会说看不到，不编。

整个学期的资料建了检索索引（精确 + BM25 融合），问一句就能翻到那一页；要念她就念给你听。

全文检索本机索引朗读

Form

三块，各干各的活

她不是一个大窗口：形象窗只管她，浮窗是工作台，宿主在本机喂数据和事件。三块各自能拖、能关、记得住位置。

形象窗

300 × 466

无边框、逐像素透明的 Live2D 窗口，只有她。头顶弹气泡，脚边弹提醒条。点空气会穿过去，点她才有反应。

浮窗

可拖 · 可缩放

8 个页签：提醒 / 今日 / 任务 / 日历 / 对话 / 错题 / 总结 / 笔记本 —— 加设置。页签位置、顺序、透明度都能改。

宿主

127.0.0.1 : 8790

本机的一个小服务：喂页面、推送事件、把她的语音送过去。只监听本机，端口带一次性钥匙，网页跨源读不到。

Privacy

她的记忆不在云上，
在 你自己的文件夹 里。

待办、错题、聊天记录、课表、你写的规矩 —— 全部是本机文件，你随时能打开、备份、删掉。 她要用模型的时候，走的是你自己填的那把 key。

01

本机文件，随时能看

纯 JSON / Markdown，没有加密黑盒。换机器拷过去就能接着用。

02

钥匙在你手里

模型走你填的 API key，多把钥匙按用途分（决定 / 干活 / 另一个她），随时能停。

03

只开在 127.0.0.1

宿主只监听本机、端口上锁；跨源网页读不到她的钥匙，也发不了指令。

04

她认得边界

外部原文只当资料不当规矩；看不懂的题说"看不到"；要动你的东西先问。

FAQ

动手之前想知道的几件事

她需要联网吗？

只有调模型和用 Edge 语音时需要。数据、待办、错题本、检索索引全在本机；断网她还在，只是暂时不说话。

要我自己填 API key 吗？

是。她在设置页里填，钥匙存在本机文件里。你可以填一把，也可以按用途分几把（一把决定、一把干活、一把给另一个她）。

会不会偷看我的东西？

她只能读你放进「投放区」的文件和你的资料目录；每一步读写在日志里。危险动作（删东西、动系统设置）默认先问你。

她说的东西可靠吗？

她会给依据：查资料会带出处；看不懂的题她说看不到，不编；讲错了你纠正她，她会记进经验本。

占资源吗？

她按 20~30 帧渲染、低性能档更省；空闲时会自己睡觉。实测一台没有独显的轻薄本常驻也没压力。

桌面上的她是自己画的吗？

不是。桌面形象用的是**第三方授权的 Live2D 模型**（CC BY-NC-SA 4.0，**非商业**）： 角色原作 上善无形（原创 OC「溟月」）→ 二次设计 ZipZipPipe（女仆鲸鱼娘）→ Live2D 化 氵六青。 这套素材**不允许出售**，本项目也**不收费**。
